# Three Editor Columns

Use `C:\Users\samjo\Desktop\OpenAI\launch-calexp5-columns.cmd` to open the CalExp5 3-role workspace and one starter file from each role repo in a single VS Code window.

## Goal
- Column 1: Worker 1
- Column 2: Worker 2
- Column 3: Integrator

## Fast Setup
1. Run `launch-calexp5-columns.cmd`.
2. In VS Code, press `Ctrl+\` twice to create three editor groups.
3. Move each `AGENTS.md` tab into its own column.

- Worker 2: `C:\Users\samjo\Desktop\OpenAI\Worktrees\CalExp5-worker-2\AGENTS.md`
